# BoxMate v1.3.5

- Fix installation of external or catalogue mods whose required dependency uses GitHub's legacy raw manifest URL format.
- Use one canonical manifest identity during catalogue loading, install ordering, and uninstall dependency checks.
- Boxroom Cats now correctly installs Boxroom LocalWorkshop first without a missing dictionary-key error.

The Windows and native Linux archives contain the complete self-contained runtime. Live Steam Deck/Proton interaction remains untested for this release.
