# BoxMate v1.4.5

- Experimental projects now display purple cards, an EXPERIMENTAL badge, and a warning icon explaining that they may break or behave unexpectedly.
- Enable the warning with `"experimental": true` in a project manifest or its catalogue entry. Existing manifests remain compatible.
- Deprecated projects retain their red unsupported styling.

Includes complete self-contained Windows and Linux runtimes. Linux/Steam Deck interaction has not been tested for this release.
