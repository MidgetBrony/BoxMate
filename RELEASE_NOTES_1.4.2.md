# BoxMate v1.4.2

- Add a **Reinstall** action for mods and tools that BoxMate considers installed and current.
- Reinstall the selected package through the normal verified download, backup, and installation flow.
- Keep already-current required dependencies untouched during a reinstall.

The Windows and native Linux archives contain the complete self-contained runtime. Live Steam Deck/Proton interaction remains untested for this release.
