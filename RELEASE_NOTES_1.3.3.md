# BoxMate v1.3.3

- Renew expiring GitHub OAuth credentials automatically.
- If GitHub rejects a saved credential and it cannot be renewed, clear it and reload the catalogue anonymously instead of leaving the mods list empty.
- Preserve the selected BOXROOM folder immediately on Windows and Linux.
- Find BOXROOM automatically through Steam App ID `4335460`, including additional Steam libraries and native or Flatpak Steam locations on Linux/Steam Deck.

The Windows and native Linux archives contain the complete self-contained runtime. Live Steam Deck/Proton interaction remains untested for this release.
