# BoxMate v1.3.4

- Treat GitHub's legacy and current raw manifest URL formats as the same source.
- Fix false duplicate package ID errors when an external repository depends on a mod that is already present in the official catalogue.
- Apply the same URL normalization to minimum-version dependency checks.

The Windows and native Linux archives contain the complete self-contained runtime. Live Steam Deck/Proton interaction remains untested for this release.
