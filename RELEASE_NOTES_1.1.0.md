# BoxMate 1.1.0

## Added

- Installed mods can now be uninstalled directly from their mod card.
- Uninstalling removes only BoxMate-recorded files, preserves shared package files, and protects dependencies still required by installed mods.
- BoxMate now checks for its own updates and can download, verify, install, restart, and relaunch the appropriate Windows or Linux full-runtime release.

## Improved

- Missing installed files now show a clearer **Repair** action.
- MelonLoader remains independently managed and is never removed with a mod.

Windows and Linux downloads contain the complete self-contained runtime output.
