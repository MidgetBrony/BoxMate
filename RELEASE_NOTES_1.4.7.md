# BoxMate v1.4.7

- Check for BoxMate updates before refreshing the catalogue, so a broken catalogue can never hide the updater.
- Isolate failures to the affected catalogue entry instead of rejecting every mod and tool.
- Keep valid projects visible and report how many catalogue entries were unavailable.
- Retain the repository dependency-link fix from 1.4.6.

Includes complete self-contained Windows and Linux runtimes. Linux/Steam Deck interaction has not been tested for this release.
