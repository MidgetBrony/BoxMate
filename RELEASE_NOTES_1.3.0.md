# BoxMate v1.3.0

BoxMate now installs and updates BOXROOM companion tools as first-class packages.

## New

- Install, update, repair, open, and uninstall BR-QImport directly from BoxMate.
- Install, update, repair, open, and uninstall Boxroom Studio directly from BoxMate.
- Automatically select the Windows x64 or Linux x64 tool release for the current operating system.
- Install tools separately in BoxMate's per-user application-data directory; a BOXROOM folder is not required.
- Launch BOXROOM directly through Steam App ID `4335460` from the new header button.

## Safety

- Tool downloads use the same GitHub SHA-256 verification, staging, backup, and rollback protections as mod installs.
- Linux tool entry points have their executable permission restored after extraction.
- Existing BOXROOM mod destination restrictions remain unchanged.
